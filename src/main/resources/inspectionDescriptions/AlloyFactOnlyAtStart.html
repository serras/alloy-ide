Reports a fact over mutable state that, without always, constrains only the start of the trace.

A fact that constrains the next state, with ', after or a call to an event predicate, outside every always, eventually, until and releases, constrains only the transition out of the first state. In this example, inbox may change freely afterwards:

fact { all n: Node | n.inbox' = n.inbox }

A fact that mentions a var field or var sig but uses no temporal operator at all constrains only the first state. This is often deliberate, as in fact init { no inbox }, so it is reported only as information, without highlighting.

Signature facts are not reported, since the analyzer applies them in every state.

The quick-fix wraps the body of the fact in always { … }.
