Reports e' where e mentions no var field or var sig, directly or through the functions it calls, so that e' is the same as e.

Quantified variables and the parameters of predicates and functions also keep their value across states. In these examples, succ is a static field:

pred step { inbox' = inbox + succ' }
pred unchanged[r: Node -> Node] { r' = r }

To prime an argument, declare a macro instead: let unchanged[r] { r' = r }.

The quick-fix removes the prime.
