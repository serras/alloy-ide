Reports an event predicate that leaves some var field or var sig unconstrained in the next state, so that it can change freely when the event occurs.

A predicate is an event when it constrains the next state, with ' or after, directly or through the predicates and macros it calls, and uses no always, eventually, until, releases or ;. A relation is constrained when it is mentioned under ' or after in any branch of the body. In this example, outbox is not:

pred send[n: Node] {
  some i: n.outbox | inbox' = inbox + n.succ->i
}

The quick-fixes add f' = f for one relation or for all of them.
