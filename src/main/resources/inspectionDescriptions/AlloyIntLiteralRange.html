Reports an integer literal larger than the largest integer of a command that depends on it, which the analyzer silently wraps around.

A command uses the bitwidth of its int scope, or 4 by default, for integers from -8 to 7. It depends on the literals of its body, of every fact, and of the predicates and functions they call. In this example, 8 is read as -8:

fact { #Node =< 8 }
run example {} for 3

The quick-fixes raise the bitwidth of an affected command to the smallest one that fits the literal.
