Reports a test of emptiness or of a number of elements that a multiplicity says more simply:
  • not some e, #e = 0 and e = none are no e;
  • not no e, #e > 0, #e >= 1, #e != 0 and e != none are some e;
  • #e = 1 is one e;
  • #e =< 1 and #e < 2 are lone e.

Mirrored forms such as 0 = #e count too. The multiplicity form is also safe from integer overflow: #e wraps around when e has more elements than the bitwidth can count, so that #e = 0 may hold of a set that is not empty, while no e cannot.
