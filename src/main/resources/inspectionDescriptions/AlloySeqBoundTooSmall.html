Reports a command whose bound on sequences (the written seq scope, or the analyzer's default) is smaller than the scope of the elements of a var field declared with seq T.

In this example, an inbox holds at most 2 identifiers, fewer than the 3 nodes that could send one:

sig Node { var inbox : seq Node }
check at_least_one_leader_fair for 3 but 2 seq

The quick-fix raises the seq bound to the scope of the elements.
