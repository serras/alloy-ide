Reports a command scope that reads as an upper bound for a signature whose scope a module parameter declared exactly makes exact, as util/ordering[X] does for X.

In this example, 2 Id means exactly 2 Id atoms, so configurations with fewer of them are not analyzed:

open util/ordering[Id]
check safe for 3 but 2 Id

When the signature takes the command's overall scope, as in for 4, the problem is reported without highlighting. The quick-fix writes the scope as exactly.
